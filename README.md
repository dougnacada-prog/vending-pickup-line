One line, at most 200 characters: a pickup line a vending machine would use on a passing human — spoken by the machine itself, in its own world of trays, coils and exact change. An AI judge compares lines two at a time and picks the funnier, more machine-voiced, more charming one.

The entry:

> That thud in my tray? That's me, dropping hints since 2 a.m.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
